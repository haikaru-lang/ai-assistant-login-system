
# AI Assistant Desktop System

A modern desktop application built with Python and CustomTkinter, featuring secure user authentication and an integrated AI assistant powered by Google Gemini.

## Features
- **User Authentication:** Secure user registration and login with Bcrypt password hashing.
- **Local Database:** SQLite integration for storing user credentials.
- **AI Integration:** Interactive chat dashboard powered by the Google Gemini API.
- **Modern UI:** Built with CustomTkinter for a clean, dark-themed user interface.

## Tech Stack
- **Language:** Python
- **GUI:** CustomTkinter
- **Database:** SQLite
- **Security:** Bcrypt
- **AI SDK:** `google-genai`, `python-dotenv`
